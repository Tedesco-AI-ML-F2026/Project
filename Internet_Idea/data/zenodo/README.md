# Zenodo data

2 CSVs from the AestheticsCV deposit, so the notebooks run without the 280 MB zip:

- `wiki_ecosystem.csv` — 1,128 Aesthetics Wiki infoboxes (decade, motifs, colours, values, related aesthetics)
- `wiki_ecosystem_edges.csv` — 20,925 "related aesthetic" links

**From:** Y. J. Lin, *Internet Aesthetics Stimulus Set* (AestheticsCV), Zenodo record 20708760 — https://zenodo.org/records/20708760 (companion to "The Many Pasts of Internet Aesthetics", Cornell).
